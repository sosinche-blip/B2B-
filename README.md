# B2B Operation Master V213 — 2회 발주시간 / 서버확정 매핑 / B알림 보강

2026-08-09 수정본입니다.

## 핵심 변경
- API 상품매칭 표를 가로폭 중심으로 재배치했습니다.
  - `업체` ↔ `엑셀 연결정보` 간격 최소화
  - `기본수량`, `배송비` 입력칸을 기존 대비 약 50% 수준으로 축소
  - 데스크톱에서는 불필요한 가로 스크롤을 최대한 없앴습니다.
- 옵션별 발주시간은 `09:00` 또는 `09:00,14:00`처럼 **최대 2개**까지 허용합니다.
- 두 번째 시간은 같은 주문을 중복 발주하는 시간이 아니라 **첫 시간에 아직 발주되지 않은 신규/미처리 주문을 다시 처리할 두 번째 기회**입니다. 기존 발주이력 키로 중복 주문을 차단합니다.
- API 상품매칭은 **서버에 저장된 확정값을 기준값(source of truth)** 으로 사용합니다.
  - 표에서 발주시간/기본수량/배송비를 편집해도 임시 편집 상태입니다.
  - `수정 확정`을 눌러 AdminPlus 재검증 → 서버 저장 → 서버 재조회 검증까지 통과해야 실제 운영값이 바뀝니다.
- 자동감시 화면의 버튼 의미를 명확히 했습니다.
  - `감시기준 저장`: 해당 행의 발주시간/기본수량/배송비를 서버 확정값으로 저장
  - `현재가를 새 기준가로 적용`: 현재 공급가를 이후 가격감시의 새 기준가로 승인
  - `자동감시 설정 전체 서버저장`: 확정된 자동감시 설정 전체 저장. 미확정 행 편집값은 포함하지 않음
- B안 알림 적용
  - 웹 화면 즉시 성공/실패 메시지
  - 일일 운영 점검판에 `자동감시 저장 실패` / `가격 변동 감지` 건수 표시
  - 저장 실패 시 기존 서버 확정 운영값 유지

## 배포 순서
1. Ncloud V206 동반 수정본을 먼저 배포합니다.
2. Ncloud `/api/system/status`에서 아래를 확인합니다.
   - `version = v213-per-option-payment-toss-mapping`
   - `featureRevision = dual-time-server-lock-b-alert-20260809`
3. 그 다음 이 V213 웹앱/Worker를 Cloudflare에 배포합니다.
4. 브라우저에서 Ctrl+F5 후 API 상품매칭 화면을 확인합니다.
